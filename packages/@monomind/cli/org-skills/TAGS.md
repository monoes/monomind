# Org skill tags — controlled vocabulary

Every bundled skill carries 3-5 tags from this list, and only from this list.
Tags feed skill search (a tag hit weighs like a name hit) and `tag:<t>`
selectors in a role's `skill_pool`. Tags are lowercase, hyphenated, singular.

Pick tags in this order: one or two **domain** tags, then the **language /
framework / platform** the skill is specific to (if any), then the
**activity** or **business topic** that best names what the skill is for.
Add a tag only when someone looking for that tag should find the skill.
