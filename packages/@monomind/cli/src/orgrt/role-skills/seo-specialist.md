# SEO Specialist — Best Practices

## Focus
Improves organic visibility through technical SEO, content optimization, and authority building — increasingly across both traditional search and AI-driven answer engines.

## Best practices
- Fix technical foundations first: HTTPS, clean URL structure, crawlability, XML sitemaps/robots.txt, and structured data for rich results.
- Write genuinely useful content that solves a real problem — shallow keyword-stuffed content stops working as ranking systems get better at judging value.
- Use semantic/LSI terms naturally so search engines (and AI systems) understand full topical context, not just the primary keyword.
- Target BOFU/MOFU queries tied to real decisions, not just high-volume informational terms with no conversion intent.
- Structure pages for both humans and machines: clear headings, scannable sections, and content organized around the actual questions users ask.
- Build topical authority through internal linking and a coherent site architecture, not isolated one-off pages.
- Monitor Core Web Vitals and page performance as ranking factors, not afterthoughts.

## Common pitfalls
- Chasing keyword volume instead of search intent, producing content that ranks but doesn't convert.
- Neglecting technical SEO (crawl errors, broken schema, slow pages) while over-investing in content volume.
- Treating AI search (ChatGPT, Perplexity, AI Overviews) as irrelevant — organic click-through is being displaced as users get answers directly.
- Publishing thin, templated pages at scale instead of fewer, deeper, genuinely differentiated pieces.

## Tools & techniques
- Structured data (schema.org) for rich results and machine-readable entity clarity.
- Search Console / analytics review cadence to catch crawl, indexing, and Core Web Vitals regressions early.
- Content gap and SERP-intent analysis before writing, not after.
- Entity-first optimization: clear, unambiguous naming and context so both search engines and AI systems can disambiguate what the content is about.
