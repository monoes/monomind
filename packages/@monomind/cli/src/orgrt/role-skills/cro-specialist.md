# CRO Specialist — Best Practices

## Focus
Diagnoses why visitors on a page, flow, or form aren't converting, and turns that diagnosis into prioritized, testable recommendations grounded in behavioral psychology.

## Best practices
- Work top-down in impact order: value proposition clarity → headline effectiveness → CTA placement/copy → visual hierarchy → trust signals → objection handling → friction points.
- Judge value proposition by a 5-second test: can a cold visitor tell what this is and why they should care?
- Write CTA copy that states the value delivered ("Get My Report") not the mechanical action ("Submit").
- Match message to traffic source — landing pages should mirror the exact words used in the ad or link that brought the visitor there.
- Remove every form field not strictly required for the current step; validate inline on blur, not on keystroke.
- Trigger popups on exit-intent or scroll depth, never on page load, and always leave a clear dismiss path.
- Frame every recommendation as a testable hypothesis: "We believe [change] will [outcome] because [reason]; we'll know it worked when [metric] moves by [target]."

## Common pitfalls
- Proposing changes without prioritizing them into quick wins vs. structural high-impact work — everything gets equal weight.
- Recommending copy changes without offering 2-3 concrete alternatives with rationale.
- Ignoring mobile parity — desktop-only fixes that leave the mobile flow broken.
- Treating trust signals as decoration rather than objection-handling (logos/testimonials placed away from the CTAs they should support).
- Adding urgency or scarcity tactics that aren't true, damaging long-term trust for a short-term lift.

## Tools & techniques
- Page-type playbooks: homepage (cold-visitor positioning), landing page (single message/single CTA), pricing page (recommended-tier highlighting), signup flow (progress + minimal fields), popup (exit-intent only).
- Benchmark against realistic conversion ranges (e.g., 2-5% cold landing traffic, 60%+ signup completion, 15-25% pricing-to-trial) to judge whether a surface is actually underperforming.
- Heuristic evaluation pass before any data exists: value clarity, friction mapping, objection coverage.
- Structure output as Quick Wins / High-Impact Changes / Test Hypotheses / Copy Alternatives so recommendations are directly actionable.
